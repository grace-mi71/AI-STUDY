## 2. 주간 목표

### 📆 1주차 (3/1 ~ 3/7) — NumPy 속성 + PyTorch 입문

**목표: NumPy 브로드캐스팅/행렬연산을 자유롭게 쓸 수 있을 것**

**[1~3일차] NumPy 속성 (이것만 끝내고 PyTorch로 넘어가기)**

- 1일차 — 배열 기초
  - ndarray 생성: `np.array`, `np.zeros`, `np.ones`, `np.arange`
  - shape, dtype, reshape, flatten 직접 실습
- 2일차 — 연산
  - 브로드캐스팅 (핵심. 이게 안 되면 PyTorch에서 계속 막힘)
  - 행렬 곱: `np.dot`, `@` 연산자
  - axis 개념: axis=0, axis=1이 각각 뭔지 체감하기
- 3일차 — 인덱싱 + 마무리
  - 슬라이싱, boolean indexing, fancy indexing
  - NumPy quickstart 전체 코드 처음부터 끝까지 직접 치기

**[4~7일차] PyTorch 기초**

- PyTorch 공식 튜토리얼 "Learn the Basics" 순서대로 진행
  - Tensors → Datasets → DataLoader → Build Model → Training Loop
- NumPy ↔ PyTorch 텐서 비교하며 공부 (문법이 거의 똑같음을 체감)
- GitHub repo 생성 및 첫 커밋

### 📆 2주차 (3/8 ~ 3/14) — PyTorch 완성 + 딥러닝 기초

**목표: 튜토리얼 없이 MNIST 분류기를 혼자 짤 수 있을 것**

- PyTorch 공식 튜토리얼 완주
- EECS 498 Lecture 1~3 수강
  - Image Classification, Loss Functions, Optimization
- 실습: MNIST 분류기를 튜토리얼 완전히 닫고 기억으로 처음부터 구현
  - 안 써지는 부분 = 모르는 부분. 그 부분만 다시 찾아보기
- 개념 정리: Gradient Descent, Loss Function, Softmax

### 📆 3주차 (3/15 ~ 3/21) — 딥러닝 이론 심화 + Backprop

**목표: Backpropagation을 손으로 계산하고 코드로도 구현할 것**

- EECS 498 Lecture 4~6 수강
  - Neural Networks, Backpropagation, Training Tips
- Assignment 1 직접 구현 (kNN, Linear Classifier)
  - 남의 코드 참고 금지. 강의만 보고 직접 짜기
- EECS 498 Lecture 7~8 수강 (CNN 구조 이해)
- 개념 정리: Chain Rule, Backprop 흐름, Conv 연산 원리

### 📆 4주차 (3/22 ~ 3/31) — ResNet 논문 재현

**목표: ResNet 논문을 읽고 PyTorch로 처음부터 구현할 것**

- ResNet 논문 읽기: He et al., 2015 (arXiv:1512.03385)
- ResNet-18 PyTorch로 직접 구현
  - `torchvision.models` 사용 금지. 논문 보면서 직접 짜기
  - CIFAR-10 데이터셋으로 학습 돌려보기
- GitHub 커밋 + README 작성 (영어로 쓰는 연습도 겸하기)
- 3월 전체 회고 작성
- 4월 방향 잡기: 교수님 논문 접촉 + 논문 재현 2편째
